# Omar Musayev — personal portfolio

A light, responsive four-page portfolio for Omar Musayev, built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Assignment checklist

- **Home:** Omar's introduction and location, with a circular profile-photo uploader.
- **About:** personal background, education and qualifications, activities, interests, and a language-skills table.
- **Projects:** a Logic Gates project feature with a photo uploader, interactive NOT/AND/OR simulator, and an embedded project presentation.
- **Navigation and footer:** links connect all four pages.
- **Interactive About page:** story cards open details and award badges as they are explored.
- **Repository:** keep the source organized and include this README.
- **Development history:** make multiple commits so the repository shows your progress.

## Add project and profile photos

Use the image buttons to preview photos in the current browser session. The previews are local and reset when the page is refreshed. To publish photos permanently, place the image files in this repository and reference their paths from `index.html`.

## Run locally

Open `index.html` in a browser, or start a local static server from this folder:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a GitHub repository and add the files in this folder.
2. Push the repository to GitHub.
3. In the repository, open **Settings → Pages**, choose the main branch and root folder, and save.
4. Wait for the Pages deployment, then check the published link.

The assignment submission also asks for the published website link, the GitHub repository link, and an exported Markdown file of the AI chat.
